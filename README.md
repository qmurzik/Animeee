# AnimeApp

Нативный экспериментальный клиент iOS 18 для публичного API AniLibria. Реализованы каталог, поиск, карточка, эпизоды, выбор HLS-качества, системный AVPlayer, сохранение позиции и кнопки пропуска по меткам источника. История хранит последний тайтл. Другие провайдеры, AniSkip, автоматическое переключение источника, загрузки и остальные расширенные возможности пока не реализованы. Воспроизведение зависит от доступности и условий источника.

Сгенерируйте проект `xcodegen generate`, затем соберите в Xcode или запустите GitHub Actions. Workflow создаёт неподписанный IPA для физического устройства; для установки нужна собственная подпись совместимым sideload-инструментом. Подпись и provisioning profile в репозитории отсутствуют. На iPhone XS и на физических устройствах приложение не проверено.
