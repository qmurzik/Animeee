# AnimeApp

Нативный экспериментальный клиент iOS 18 для публичного API AniLibria. Реализованы каталог, поиск, карточка, эпизоды, выбор HLS-качества, системный AVPlayer, сохранение позиции и кнопки и необязательный автоматический пропуск по меткам источника или подходящим по длительности меткам AniSkip. История хранит до 100 последних тайтлов и позволяет продолжить просмотр. В плеере доступны выбор серии, скорость, повтор после ошибки и автоматическая следующая серия. Другие провайдеры, AniSkip, автоматическое переключение источника, загрузки и остальные расширенные возможности пока не реализованы. Воспроизведение зависит от доступности и условий источника.

Откройте `AnimeApp.xcodeproj` в Xcode или запустите GitHub Actions. `project.yml` также позволяет пересоздать проект через XcodeGen. Workflow создаёт неподписанный IPA для физического устройства; для установки нужна собственная подпись совместимым sideload-инструментом. Подпись и provisioning profile в репозитории отсутствуют. Сборка для ARM64 прошла в GitHub Actions; на iPhone XS и на физических устройствах приложение не проверено.

Сетевые проверки: `python3 -m unittest discover -s tests -v`. Подробности и ограничения: [RESEARCH.md](RESEARCH.md).
