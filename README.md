# AnimeApp

Нативный экспериментальный клиент iPhone, iOS 18+, ARM64. Сборка в `.github/workflows/build-ios.yml` создаёт неподписанный IPA, проверяет архитектуру, Info.plist и ZIP, загружает артефакт и пытается опубликовать prerelease. Дополнительная задача собирает приложение для ARM64 iOS Simulator, запускает и снимает главный экран.

## Просмотр

Основной каталог и поиск используют YummyAnime напрямую (`api.yani.tv`), с постраничной загрузкой. Карточки и серии открываются по YummyAnime ID, без обязательного соответствия AniLibria/MAL. Старые сохранённые карточки AniLibria продолжают открываться. На странице тайтла YummyAnime доступны возвращённые источником озвучки и серии. Видеобалансеры Aksor и CVH обрабатываются нативно; вход в аккаунт не добавляет поддержки других балансеров. Для старых карточек AniLibria соответствие проверяется по MAL ID; карточки YummyAnime используют свой ID напрямую. Неподдерживаемые балансеры исключены из выбора дополнительных озвучек.

- AniLibria: прямой HLS, AVPlayer, качество, скорость, история, продолжение, смена серий и метки пропуска.
- Aksor: публичный API возвращает варианты MPD/HLS/MP4; VLCKit воспроизводит совместимые потоки. Манифесты DASH с ContentProtection отклоняются.
- CVH: публичный интерфейс оригинального плеера; точное сопоставление кода студии и серии, прямые MP4 без замены возвращённых адресов.
- Дополнительный плеер: выбор озвучки на текущей серии, сетка серий, скорость, качество, перемотка, история, возобновление, автопереход. Позиция переносится при ручной смене озвучки. Совпадение позиции разных монтажных версий не гарантируется.

Проверены декодирование 4 секунд Aksor DASH и CVH MP4 через FFmpeg в Linux, API/плейлисты источников и ARM64 сборка с VLCKit. Это не проверка воспроизведения на физическом iPhone. Часть CDN недоступна из среды сборки. Ошибка конкретного источника не подтверждает недоступность всех его потоков.

## Установка

Скачайте AnimeApp-unsigned.ipa из Releases или ZIP артефакта Build iOS. Подпишите своим совместимым сертификатом через подходящий sideload-инструмент и установите. Чужие сертификаты и provisioning profiles не поставляются. Для самостоятельной сборки откройте AnimeApp.xcodeproj; Swift Package Manager загружает VLCKitSPM 3.6.0. Зависимость объёмная и нужна для DASH, который AVPlayer не поддерживает. `project.yml` позволяет пересоздать проект XcodeGen.

## Данные

Списки Смотрю, В планах, Просмотрено, Отложено, Брошено и Избранное хранятся локально. История содержит до 100 тайтлов. Импорт/экспорт JSON доступен в настройках; импорт заменяет локальную библиотеку, историю и позиции. Сейчас используется UserDefaults; миграция на SwiftData ещё не выполнена.

## Проверки и ограничения

`python3 -m unittest discover -s tests -v` — семь сетевых контрактных проверок. `node --test tests/login-bridge.test.cjs` — шесть тестов JavaScript-кода получения сессии (доверенный источник, путь API, HTTP-статус, fetch и XHR). `swift test` запускает семь Swift unit-тестов выбора/порядка серий и границ перемотки; они также выполняются в CI. Проверки на физическом устройстве пока нет. Не реализованы загрузки, автоматическое переключение при ошибке на другой источник, AniList-синхронизация, расписание, франшизы и многие расширенные функции плеера. PiP/AirPlay и точность меток на iPhone не проверены; эти функции не заявляются для VLCKit. Веб-плеер удалён.

## Аккаунт YummyAnime

Профиль открывается кнопкой в шапке главной или через Настройки → Аккаунт YummyAnime. Доступны вход на официальном сайте в отдельном окне и вход логином/паролем через тот же `POST /profile/login`, который использует YummyTV. Пароль не сохраняется. Только после успешной проверки `GET /profile` токен сохраняется в Keychain с `WhenUnlockedThisDeviceOnly`. Запросы с токеном ограничены `api.yani.tv`, перенаправления на другие хосты отклоняются. Токен не входит в JSON-экспорт библиотеки и не передаётся видеобалансерам.

Окно сайта наблюдает только успешный ответ API входа/обновления токена в главном документе официального сайта; оно не читает пароль, cookies или localStorage. Капчу решает пользователь на сайте. Если требуется вход через внешнего провайдера, его совместимость с этим окном пока не проверена. Веб-окно используется для входа, воспроизведение остаётся нативным.

Сессия проверяется при запуске; токен обновляется через `/profile/token` после двух дней. При 401 сессия очищается; временная ошибка сети не удаляет токен. Выход делает best-effort `/profile/logout` и очищает локальную сессию.

Без реального пользовательского аккаунта успешный вход, обновление токена и сайт с капчей сквозным тестом не проверены. Публичный каталог, поиск, прямые карточки/серии и пагинация проверены без входа. Не присылайте пароль в чат — ввод предусмотрен в самом приложении.

## Экран просмотра 0.5

Для Aksor/CVH экран просмотра занимает окно целиком; панели управления расположены поверх видео. Доступны касание для показа/скрытия панелей, двойное касание для ±10 секунд, блокировка управления и публичный запрос альбомной ориентации. Серии, озвучки и настройки вынесены в отдельные панели. Качество, скорость и дорожки показываются по данным потока/движка; отдельных субтитров у источника может не быть. Ползунок отправляет запрос перемотки после завершения жеста.

Исправлены сопоставление номеров 02/2, повтор завершённой серии с начала и защита сохранённой позиции при ожидающем восстановлении. Нативная проверка симулятора теперь проверяет видеовывод, паузу, перемотку, продолжение и альбомный снимок CVH. Результат конкретной сборки смотрите в Actions. Это не проверка всех источников, длительного просмотра и физического iPhone XS. Сохранённые старые карточки AniLibria используют прежний AVPlayer-экран.


## Просмотр 0.6

Экран просмотра YummyAnime теперь имеет два режима. В портретном видео закреплено сверху в формате 16:9; под ним постоянно доступна шкала времени, название и переключение серий, вкладки серий и озвучек. В альбомном видео занимает экран целиком, панели скрываются через четыре секунды и возвращаются касанием. При повороте сохраняется та же поверхность VLC.

На карточке аниме сразу доступны основная кнопка запуска/продолжения, выбор студии и сетка серий. На главной продолжение открывает сохранённый эпизод после загрузки карточки. Для длинных сериалов есть диапазоны по 50 серий и поиск номера. Предпочтение озвучки сохраняется для каждого тайтла; звёздочки поднимают избранные студии в выборе. Название студии, балансер и количество серий отображаются отдельно.

Двойное касание перематывает на 10 секунд; горизонтальный свайп показывает целевое время и перематывает при отпускании. Вертикальный свайп слева регулирует яркость, справа — локальную громкость VLC, а не системную громкость. Системный ползунок и ползунок громкости плеера доступны в настройках просмотра. Два пальца увеличивают видео; кнопка 1:1 сбрасывает увеличение. Изменённая жестом яркость восстанавливается при закрытии. При уходе в фон плеер сохраняет позицию и ставится на паузу. Скорость запоминается; качество по умолчанию и запуск в альбомном режиме задаются в настройках.

Постеры декодируются до 650 пикселей, кэш декодированных изображений ограничен 32 МБ. Очереди серий готовятся заранее; сетка не перерисовывается на каждом обновлении времени. Это меры ограничения нагрузки, а не результат профилирования физического iPhone XS.

Поддержка источников не расширилась: нативные Aksor/CVH и прежний AVPlayer для сохранённых AniLibria. Пропуск по меткам/AniSkip пока относится к AniLibria. Новые жесты, блокировка и локальная громкость не заменяют проверку на устройстве. CI проверяет два конкретных потока, паузу, продолжение и попадание перемотки в диапазон 13–23 секунды после запроса 15 секунд; все серии и точность до кадра не проверены.


## Исправления 0.7

Зоны жестов ограничены областью видео и не перекрывают заголовок, шкалу времени и нижнюю панель. Поверхность VLC не принимает касания; управление имеет отдельный верхний слой. В проект добавлен UI test target `AnimeAppUITests`: он открывает плеер через полноэкранную презентацию поверх приложения, нажимает кнопку полного экрана, качество, озвучки, серии и меню, меняет качество на 480p и проверяет настройки после возврата в портретный режим. Тест использует настоящие координатные нажатия XCTest, а не прямой вызов методов плеера. Результат конкретного запуска находится в Actions.

Добавлен полный AppIcon asset catalog для iPhone и App Store, с непрозрачными PNG. CI проверяет `CFBundleIcons` и `Assets.car` в собранном приложении. Отдельный UI-тест делает снимок установленной иконки на SpringBoard симулятора.

В карточке появился раскрываемый раздел «Видео Shikimori» для трейлеров, опенингов и клипов из настоящего API; они открываются на видеоплатформе источника. Полные эпизоды в проверенном ответе API не обнаружены. Статус Anilib (отдельного от AniLibria), AnimeGo и границы этой интеграции: [SOURCES-0.7.md](SOURCES-0.7.md).
