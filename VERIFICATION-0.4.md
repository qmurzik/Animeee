# AnimeApp 0.4.0 (26): YummyAnime

IPA: https://github.com/qmurzik/Animeee/releases/download/build-26/AnimeApp-unsigned.ipa
Source: https://github.com/qmurzik/Animeee/tree/build-26
CI: https://github.com/qmurzik/Animeee/actions/runs/41633756081

Дата проверки: 2026-11-03.

Подтверждено:

- Основной каталог, поиск, карточки и список видео загружаются непосредственно из YummyAnime по его ID. Ни AniLibria, ни наличие MAL ID не являются условием открытия карточки.
- Пагинация /anime: две страницы по 30 записей, без пересечений. Прямая карточка /anime/111 и 1353 записи /anime/111/videos доступны без сопоставления с AniLibria.
- Шесть сетевых контрактных проверок прошли: AniLibria, AniSkip, YummyAnime matching, независимый каталог и пагинация, Aksor, CVH.
- Шесть тестов JavaScript-кода окна входа прошли на тестовых ответах: доверенный сайт/хост API, путь, успешный HTTP-статус, fetch и XHR.
- Xcode собрал приложение для физического iPhone ARM64, минимальная iOS 18.0. В скачанной IPA проверены ZIP и метаданные 0.4.0 (26).
- SHA256: 84f1ce5951876fb497a500215b4b0d2acd867c452cd5e218dc5ce856986b0c8e.
- На iOS Simulator запущено приложение; снимок главной визуально проверен: https://github.com/qmurzik/Animeee/releases/download/build-26/home.png
- Нативный тест Aksor подтвердил видеовывод и продвижение до 2.49 секунды; CVH — до 2.15 секунды. Снимки и журналы в том же Release.

Реализованный вход: официальный сайт в отдельном окне либо POST /profile/login, затем обязательная проверка /profile и запись токена в Keychain. Капчу решает пользователь на сайте. Пароль не сохраняется; cookies и localStorage скрипт не читает. Токен передаётся только api.yani.tv, не видеосерверам. Выход очищает локальную сессию сразу. Запоздавшее обновление сессии проверяет её поколение и текущий токен.

Не проверено:

- Успешный вход реальным аккаунтом, капча, внешние способы входа и обновление настоящего токена. Реальных учётных данных для проверки нет; тестовые ответы не заменяют такой тест.
- Установка и длительный просмотр на физическом iPhone XS, память, нагрев, PiP и AirPlay.
- Все тайтлы и все озвучки: сервис определяет их доступность; тесты первых кадров не проверяют серию целиком.

Нативные видеобалансеры пока только Aksor и CVH, плюс старые карточки AniLibria. Kodik, Alloha и прочие балансеры не становятся поддерживаемыми после входа; приложение показывает причину отсутствия совместимого потока. Списки и история аккаунта YummyAnime пока не синхронизируются с локальной библиотекой. Подпись для установки IPA пользователь выполняет своим совместимым сертификатом.
